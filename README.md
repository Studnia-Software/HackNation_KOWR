# HackNation 2026

To repozytorium zawiera kod źródłowy aplikacji wspierającej nawodnienie w rolnictwie. Projekt realizowany jako rozwiązanie zadania udostępnionego przez agencje KOWR, pt. "Zatrzymaj wodę, chroń plony – Inteligentne wsparcie gospodarowania wodą w rolnictwie".

## Web

Front-end to combo zwajbkodowane w niewidomo czym dokładnie, trochę JavaScript i trochę Pythona.
