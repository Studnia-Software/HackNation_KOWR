# HackNation 2026

To repozytorium zawiera kod zródłowy aplikacji wspierającej nawodnienie w rolnictwie. Projekt realizowany jako rozwiązanie zadania udostępnionego przez agencje KOWR, pt. "Zatrzymaj wodę, chroń plony – Inteligentne wsparcie gospodarowania
wodą w rolnictwie".

## Web

Uruchomienie:

1. Zainstaluj `Node.js.
2. Przejdź do katalogu `/web`.
3. Przywróć pakiety npm: `npm i`.
4. Uruchom aplikacje: `npm start`.
